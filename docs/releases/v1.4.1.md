# v1.4.1 - 仓库治理与生产安全加固补丁

发布日期：2026-07-29

## Highlights

- 顶层 `node_modules` 退出 Git 跟踪，新增 `.gitattributes` 固定跨平台换行规则，日常 Diff 只保留真实项目改动。
- 更新兼容范围内的关键依赖与安全覆盖版本，并为生产环境启用可配置 CSP。
- 生产配置只保留非敏感示例，真实 JWT、PM2 确认令牌与本机配置统一写入忽略跟踪的 `detection-api/.env`。
- 后端测试排除 `dist` 编译产物，运行态同步测试不再受本机 3006/8006 监听影响。
- 生产冷启动就绪超时调整为 60 秒，应用总览优先展示正在运行的应用。

## Included Work

- `.gitattributes` 统一 Node/前端源码与配置文件使用 LF，PowerShell 与批处理脚本使用 CRLF。
- `.gitignore` 扩展环境文件、数据库与备份文件规则，降低敏感配置和运行数据误提交风险。
- `detection-api/src/server.ts` 新增可配置 Content Security Policy，支持额外 API、WebSocket 与 iframe 来源。
- 根项目、Detection API 与主门户更新 Axios、js-yaml、form-data、Multer、Morgan、PostCSS 等兼容修复版本。
- `detection-api/vitest.config.ts` 排除 `dist` 和 `node_modules`，避免重复执行编译后的测试。
- PM2 状态同步回归测试显式模拟端口未监听，不再依赖开发机的实时端口状态。
- `main-portal/vite.config.ts` 适配 Vite 8 vendor chunk 划分，生产 source map 改为显式开关。
- Windows 配置初始化脚本修正 `configs` 路径，并统一将本机配置写入 `detection-api/.env`。

## Compatibility And Security

- 本次为 `1.4.0` 的补丁版本，不包含应用数据结构或公共 API 的破坏性变更。
- 前端 npm 高危审计项已清零；ECharts 5 依赖链仍有上游中危公告，后续将在 ECharts 6 迁移中处理。
- 根目录 Swagger 工具链、后端 Express 4/Archiver/Joi 17 仍有需要上游修复或大版本迁移的公告项，本次未采用高风险强制覆盖。
- 生产部署必须从示例复制生成 `detection-api/.env`，并填写随机 `JWT_SECRET` 与 `PM2_CONFIRMATION_TOKEN`。
